Jelly QoL

QoL

These settings apply to all accounts in the server web client. Other open clients update within 30 seconds.

Services

Configure shortcuts in the header. Leave a URL empty to hide that shortcut.

Import supported settings from a JS Injector JSON export. Scripts are read as text and are never executed.

Announcements

Optional home-page message. Display limits and dismissal are remembered separately for each account in this browser. A changed message starts a new announcement.

Hide movies and entire series from non-administrator accounts.

Hidden titles

Restore all titles before uninstalling the plugin. Refresh open clients to update their lists.

Optional user groups

Without groups, hidden titles are visible only to administrators.

Group members

Each group has its own optional one-time reveal date and time. The scheduled task checks once a minute.
